HOW THE LAYERS TALK TO EACH OTHER (Connection Summary)
================================================================

  Frontend (React)
      │
      │── HTTP GET ────────────────► Supabase (read skills data)
      │── HTTP POST ──────────────► Vercel API (download request)
      │── Freighter API ──────────► Stellar (wallet connect)
      │── Freighter popup ────────► Human buyer confirms payment
      │
  Vercel Serverless Functions
      │
      │── reads/writes ───────────► Supabase PostgreSQL
      │── fires HTTP 402 ─────────► x402 Protocol
      │── verifies transaction ───► Stellar testnet RPC
      │── generates signed URL ───► Supabase Storage
      │── saves new listing ──────► Supabase skills table
      │
  AI Agent (OpenClaw / Node.js script)
      │
      │── GET /api/skills ────────► Vercel API (discover skills)
      │── POST /api/download/:id ─► Vercel API (trigger x402)
      │── x402 auto-payment ──────► Stellar testnet (USDC)
      │── receives JSON ──────────► Uses skill immediately

DIAGRAM 2 — HUMAN BUYER USER FLOW
How a human developer buys a skill on Skillnet
================================================================

  ┌──────────────────────────────────────────────────────┐
  │                   HUMAN BUYER                        │
  └──────────────────────────┬───────────────────────────┘
                             │
                             ▼
  ┌──────────────────────────────────────────────────────┐
  │  1. Lands on Skillnet home page                      │
  │     Reads hero section, understands the product      │
  │     Clicks "Browse Skills" button                    │
  └──────────────────────────┬───────────────────────────┘
                             │
                             ▼
  ┌──────────────────────────────────────────────────────┐
  │  2. Connects Freighter wallet                        │
  │     Clicks "Connect Wallet" in top right             │
  │     Freighter browser extension popup opens          │
  │     User approves the connection                     │
  │     Their Stellar address now shows in the header    │
  └──────────────────────────┬───────────────────────────┘
                             │
                             ▼
  ┌──────────────────────────────────────────────────────┐
  │  3. Browses the catalog                              │
  │     Sees skill cards with name, category, price      │
  │     Filters by category (AI, Crypto, Backend etc.)   │
  │     Uses search bar to find specific skills          │
  └──────────────────────────┬───────────────────────────┘
                             │
              ┌──────────────┴──────────────┐
              │                             │
     clicks View Details            clicks Buy Now
              │                             │
              ▼                             ▼
  ┌──────────────────────┐     ┌────────────────────────┐
  │  Skill Detail Page   │     │  x402 fires directly   │
  │  Reads full desc     │     │  from catalog card     │
  │  Sees file contents  │     │  No page change needed │
  │  Clicks Download     │     └────────────┬───────────┘
  └──────────┬───────────┘                  │
             │                              │
             └──────────────┬───────────────┘
                            │
                            ▼
  ┌──────────────────────────────────────────────────────┐
  │  4. Server fires HTTP 402                            │
  │     Vercel serverless function receives request      │
  │     Returns: price + seller Stellar address          │
  │     Example: "Pay 1.50 USDC to G...xyz"              │
  └──────────────────────────┬───────────────────────────┘
                             │
                             ▼
  ┌──────────────────────────────────────────────────────┐
  │  5. Freighter wallet popup appears on screen         │
  │                                                      │
  │     ┌────────────────────────────────────┐           │
  │     │  Freighter                         │           │
  │     │  ─────────────────────────────     │           │
  │     │  Sending: 1.50 USDC                │           │
  │     │  To: G...xyz (seller wallet)       │           │
  │     │  Network: Stellar Testnet          │           │
  │     │                                    │           │
  │     │  [Approve]          [Reject]       │           │
  │     └────────────────────────────────────┘           │
  │                                                      │
  │  Human reads the details and clicks Approve          │
  │  Their money does not move until this click          │
  └──────────────────────────┬───────────────────────────┘
                             │
                             ▼
  ┌──────────────────────────────────────────────────────┐
  │  6. Payment settles on Stellar testnet               │
  │     Transaction confirmed in approximately 5 seconds │
  │     Transaction ID generated on-chain                │
  │     USDC lands in seller Stellar wallet instantly    │
  └──────────────────────────┬───────────────────────────┘
                             │
                             ▼
  ┌──────────────────────────────────────────────────────┐
  │  7. Vercel function verifies the transaction         │
  │     Checks Stellar testnet for payment confirmation  │
  │     Matches transaction amount and address           │
  │     Generates signed download URL from Supabase      │
  └──────────────────────────┬───────────────────────────┘
                             │
                             ▼
  ┌──────────────────────────────────────────────────────┐
  │  8. Skill zip file downloads to buyer computer       │
  │     Browser automatically starts download            │
  │     File contains:                                   │
  │       - skill.json  (manifest and metadata)          │
  │       - index.js    (the skill logic and code)       │
  │       - README.md   (how to install and use it)      │
  │       - example.js  (usage example for the agent)    │
  └──────────────────────────────────────────────────────┘

  Total experience time: approximately 15 seconds
  including wallet popup and Stellar confirmation

DIAGRAM 5 — THE PAYMENT FLOW
How money moves through Skillnet
================================================================

  BUYER has USDC in Freighter or Smart Wallet
             │
             ▼
  ┌─────────────────────┐
  │   x402 Protocol     │  ← HTTP 402 Payment Required
  │   Vercel Function   │    triggers on download request
  └──────────┬──────────┘
             │
             │ Payment instruction sent to buyer wallet
             │ Amount + seller Stellar address
             ▼
  ┌─────────────────────┐
  │  Stellar Testnet    │  ← USDC transfer settles here
  │  Settlement Layer   │    in approximately 5 seconds
  └──────────┬──────────┘
             │
             │ Funds go directly to seller
             │ Platform takes zero cut
             ▼
  ┌─────────────────────────────────────────────┐
  │                                             │
  │  100% ──────────────────► Seller wallet     │
  │                           (their Stellar    │
  │                            address)         │
  │                                             │
  │  $0 ────────────────────► Skillnet platform  │
  │                           (no middleman     │
  │                            no platform fee) │
  │                                             │
  └─────────────────────────────────────────────┘

  Note: For hackathon demo, Skillnet takes no platform cut.
  In production, a small percentage could be added
  via the x402 middleware configuration.

  Human buyer flow:
  Freighter popup → human approves → Stellar settles → file released

  Agent buyer flow:
  Smart wallet auto-pays → Stellar settles → JSON returned

DIAGRAM 6 — THE TWO ENTRANCES
Human UI vs Agent API — same platform, different doors
================================================================

  SKILLNET PLATFORM
  ─────────────────────────────────────────────────────────

  ENTRANCE 1 — Human Door (Frontend)
  ─────────────────────────────────────────────────────────

  Skillnet.vercel.app/              Home page
  skillnet.vercel.app/catalog       Browse skills
  skillnet.vercel.app/skills/:id    Skill detail + download
  skillnet.vercel.app/list-skill    Seller listing form
  skillnet.vercel.app/dashboard     Seller earnings page

  Who uses this: Human developers and sellers
  Interface: React pages, buttons, Freighter popup
  Response type: Visual HTML pages

  ─────────────────────────────────────────────────────────

  ENTRANCE 2 — Agent Door (Backend API)
  ─────────────────────────────────────────────────────────

  skillnet.vercel.app/api/skills           All skills JSON
  skillnet.vercel.app/api/skills/:id       One skill JSON
  skillnet.vercel.app/api/categories       Categories JSON
  skillnet.vercel.app/api/download/:id     x402 payment gate
  skillnet.vercel.app/api/list-skill       POST new listing
  skillnet.vercel.app/api/dashboard/:addr  Seller stats JSON

  Who uses this: AI agents (OpenClaw, custom scripts)
  Interface: Pure JSON API, no visual UI
  Response type: Structured JSON data

  ─────────────────────────────────────────────────────────

  Both entrances hit the same Supabase database.
  Both payments go through the same x402 endpoint.
  Both settle on the same Stellar testnet.
  Different doors. Same building.

DIAGRAM 7 — SKILL FILE STRUCTURE
What a buyer receives after payment
================================================================

  Human buyer receives a .zip file containing:
  ─────────────────────────────────────────────

  crypto-price-watcher/
  │
  ├── skill.json
  │     {
  │       "name": "Crypto Price Watcher",
  │       "version": "1.0.0",
  │       "description": "Fetches live crypto prices",
  │       "author": "G...seller_address",
  │       "category": "crypto",
  │       "price": 0.001
  │     }
  │
  ├── index.js
  │     The actual skill logic and code.
  │     A JavaScript function that fetches
  │     live crypto prices from an API.
  │     This is what the agent calls.
  │
  ├── README.md
  │     Plain English explanation of the skill.
  │     How to install it, how to use it,
  │     what parameters it accepts,
  │     what it returns.
  │
  └── example.js
        Shows exactly how to plug the skill
        into an OpenClaw agent or any other
        agent framework. Ready to copy and run.

  ─────────────────────────────────────────────

  AI Agent receives JSON directly (no zip):
  ─────────────────────────────────────────────

  {
    "skill_id": "crypto-price-watcher",
    "endpoint": "https://skillnet.vercel.app/...",
    "method": "GET",
    "auth": "x402",
    "parameters": {
      "coin": "string (e.g. BTC, ETH, SOL)"
    },
    "returns": {
      "price": "number",
      "change_24h": "number",
      "timestamp": "string"
    },
    "cost_per_call": "0.001 USDC"
  }

  Agent reads this JSON, understands the endpoint,
  and immediately starts calling the skill API.
  No zip. No README. Machine readable only.
